# 新手起步指南

> 这份文档是给"第一次做项目、很多名词没听过"的人写的。
> 每一步都写了：敲什么、应该看到什么、错了怎么办。
> **不需要背，照着做，遇到不认识的字回来查第二节。**

---

## 一、开始之前：先搞清楚你手上有什么

你这台电脑上一共有 **5 个 Python**，这不是你的错，是装各种软件时被顺带装上的：

| 位置 | 版本 | 说明 |
|---|---|---|
| `D:\environmen\anaconda\2024` | 3.11.7 | Anaconda 自带，**我们用它** |
| `C:\Users\HUAWEI\AppData\Local\Programs\Python\Python310` | 3.10.10 | 早期装的老版本 |
| `C:\Python314` | 3.14.0 | 某个软件装的 |
| `D:\uv_python\...\cpython-3.12.13` | 3.12.13 | uv 工具装的 |
| WorkBuddy 内置 | 3.13.12 | 只给 WorkBuddy 自己用 |

**这意味着什么**：你在终端敲 `python`，系统会按顺序找到第一个，到底是哪个说不准。
新手最经典的困惑——"我明明 `pip install` 了，为什么 `import` 说找不到"——99% 是因为**装到了一个 Python，运行用的是另一个**。

所以我们的铁律：**每一个项目都建自己的虚拟环境，之后所有命令都在虚拟环境里执行。**
这样永远不用猜"我用的是哪个 Python"。

## 二、名词词典

看不懂的先跳过，遇到的时候回来查。**不用背。**

### 2.1 操作系统与命令行

| 名词 | 白话解释 | 类比 |
|---|---|---|
| **终端 / 命令行** | 一个黑框窗口，你用打字代替点鼠标来操作电脑 | 不用菜单点菜，直接跟服务员报菜名 |
| **PowerShell** | Windows 自带的终端程序，我们要用的就是它 | 服务员的一种 |
| **目录** | 就是"文件夹" | 抽屉 |
| **路径** | 一个文件/文件夹的完整地址，如 `D:\Saturns_firstProject\README.md` | 快递地址 |
| **`cd`** | change directory，切换当前所在目录 | 走进另一个房间 |
| **`pwd`** | 打印我现在在哪个目录 | 看门牌号 |

### 2.2 Python 相关

| 名词 | 白话解释 | 类比 |
|---|---|---|
| **Python 解释器** | 一个能读懂 `.py` 文件并执行它的程序。`python.exe` 就是它 | 翻译官 |
| **pip** | Python 的"应用商店"，用来下载别人写好的代码包 | 应用商店 |
| **包 / 库 / 依赖** | 别人写好、可以直接拿来用的代码集合。"依赖"是同一个东西的另一种叫法——强调"我的项目依赖它才能跑" | 现成的工具箱 |
| **`requirements.txt`** | 一个清单文件，列出这个项目需要哪些包 | 购物清单 |
| **虚拟环境（venv）** | 一个独立的文件夹，里面有一套**只属于这个项目**的 Python 和包。项目 A 装了什么，完全不影响项目 B | 给这个项目单独配一个工具箱，不和别的项目混用 |
| **激活（activate）** | 告诉终端"接下来用这个虚拟环境里的 Python" | 打开这个工具箱，之后拿工具都从这儿拿 |
| **环境变量** | 存在系统里的一组"全局便签"，程序可以读到 | 贴在冰箱上的便条 |
| **`.env` 文件** | 项目根目录下的一个文本文件，专门放密码、密钥这类不能写进代码的东西 | 装钥匙的小本子，不随身带出门 |
| **模块（module）** | 一个 `.py` 文件。`app/config.py` 就是 `app` 包下的 `config` 模块 | 一本书的一章 |
| **`import`** | 把别的模块拿进来用 | `from 工具箱 import 螺丝刀` |

### 2.3 大模型与 RAG

| 名词 | 白话解释 | 类比 |
|---|---|---|
| **API** | 一个程序对外的"服务窗口"。你按格式发请求，它按格式回结果。你不需要知道它内部怎么实现 | 餐厅点菜窗口，你不用进厨房 |
| **API Key** | 一串字符，证明"这次请求是你发的"，也用来计费 | 门禁卡 + 饭卡 |
| **LLM（大语言模型）** | 能读懂人话、生成人话的模型，比如 GPT、DeepSeek、GLM | 一个读了很多书、很会写字的人 |
| **token** | 模型处理文字的最小单位。约等于"字"，中文一个字大约 1~2 个 token。计费和长度限制都按它算 | 字数统计 |
| **Embedding（向量化）** | 把一段文字变成一串数字。**意思相近的文字，数字串也相近**——这是所有语义搜索的基础 | 给每句话在地图上标一个坐标，意思相近的离得近 |
| **向量** | 就是一串数字，比如 512 个小数 | 地图上的一个坐标点 |
| **维度** | 这串数字有多长。`bge-small-zh` 是 512 维 | 地图是几维空间 |
| **余弦相似度** | 衡量两个向量方向有多接近，取值 -1 到 1，越大越像 | 比较两个箭头是不是指向同一个方向 |
| **RAG** | Retrieval-Augmented Generation，"先查资料，再回答" | 开卷考试：先翻书找到相关段落，再组织答案 |
| **分块（chunk）** | 把长文档切成一小段一小段，每段能独立看懂 | 把一本书撕成一张张纸条 |
| **检索（retrieval）** | 从一堆纸条里，找出和问题最相关的几张 | 按关键词翻目录找页 |
| **索引（index）** | 预先算好、存起来的数据结构，让"查找"变快 | 书的目录，不用从头翻 |
| **幻觉** | 模型一本正经地编造不存在的事实 | 不懂装懂 |
| **prompt** | 你发给模型的指令文本 | 给演员的剧本 |

### 2.4 工程与版本控制

| 名词 | 白话解释 | 类比 |
|---|---|---|
| **FastAPI** | 一个 Python 的 Web 框架，帮你在几十行内做出一个 HTTP 服务 | 盖房子用的脚手架 |
| **接口 / 路由** | 一个 URL 地址 + 一种操作，比如 `POST /ask` | 楼里的一个门牌号 |
| **JSON** | 一种文本格式，长得像 `{"question": "你好"}`。程序之间传数据基本都用它 | 通用的表格格式 |
| **git** | 版本控制工具，记录你每次改了什么，可以回退 | 游戏存档 |
| **仓库（repository）** | 一个被 git 管理的项目文件夹 | 一个存档槽 |
| **commit** | 一次"存档"，附带一句说明 | 存档 + 备注 |
| **traceback（报错堆栈）** | 报错时那一大段文字。**从下往上看**，最后一行是错误类型和原因，上面是调用路径 | 事故现场的责任链 |

## 三、搭建环境（照着敲，7 步）

> 全程用 **PowerShell**。下面每条命令都可以直接复制粘贴。

### 第 1 步：打开 PowerShell，进入项目目录

打开方式：按 `Win` 键 → 输入 `powershell` → 回车。

然后逐条粘贴：

```powershell
cd D:\Saturns_firstProject
```

**应该看到**：提示符变成 `PS D:\Saturns_firstProject>`。

**如果报错** `找不到路径`：先确认你的项目是不是在这个位置。可以在文件资源管理器里打开项目文件夹，点一下地址栏，把路径复制出来替换。

> 小技巧：在文件资源管理器里打开项目文件夹 → 点地址栏 → 输入 `powershell` → 回车，会直接在当前目录打开终端，不用 `cd`。

---

### 第 2 步：确认我们要用的那个 Python 能跑

```powershell
D:\environmen\anaconda\2024\python.exe --version
```

**应该看到**：`Python 3.11.7`

**为什么不用直接敲 `python`**：你机器上有 5 个，直接敲不确定是哪个。这里写全路径，等于明确指认"就要这一个"。麻烦一次，之后就不会错。

**如果报错** `系统找不到指定的路径`：说明 Anaconda 不在这个位置。敲 `where python` 看看有哪些，把结果发我。

---

### 第 3 步：创建虚拟环境

```powershell
D:\environmen\anaconda\2024\python.exe -m venv .venv
```

这条命令在说什么：`用这个 Python，执行 venv 模块，在当前目录创建一个叫 .venv 的虚拟环境`。

**应该看到**：**什么都没输出**，等 10~30 秒后回到提示符。**没输出就是成功。**

**验证一下**：

```powershell
.\.venv\Scripts\python.exe --version
```

**应该看到**：`Python 3.11.7`

**如果报错** `无法将".\.venv\Scripts\python.exe"项识别为...`：说明上一步没成功，`.venv` 文件夹没建出来。敲 `dir` 看看有没有 `.venv`。

---

### 第 4 步：激活虚拟环境

```powershell
.\.venv\Scripts\Activate.ps1
```

**应该看到**：提示符最前面多了一个 `(.venv)`：

```
(.venv) PS D:\Saturns_firstProject>
```

**这个括号就是"我现在在虚拟环境里"的标志。以后每条命令执行前，先看一眼有没有这个括号。**

**⚠️ 大概率会遇到的坑**：报错类似

```
无法加载文件 ...\Activate.ps1，因为在此系统上禁止运行脚本。
```

这是 Windows 默认的安全策略（防止乱跑脚本），不是你的错。执行下面这行解除限制（**只影响你当前用户，是安全的**）：

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned -Force
```

然后再执行一次激活命令。之后这个坑就永久没了。

---

### 第 5 步：升级 pip，装第一批依赖

```powershell
python -m pip install --upgrade pip
```

```powershell
python -m pip install fastapi "uvicorn[standard]" pydantic-settings python-multipart pypdf python-docx openai pytest httpx
```

**应该看到**：一堆 `Collecting ...` `Downloading ...`，最后一行 `Successfully installed ...`。

**耗时**：2~5 分钟。

**如果下载特别慢或超时**，换国内镜像源（在命令末尾加一段）：

```powershell
python -m pip install fastapi "uvicorn[standard]" pydantic-settings python-multipart pypdf python-docx openai pytest httpx -i https://pypi.tuna.tsinghua.edu.cn/simple
```

**验证**：

```powershell
python -m pip list
```

**应该看到** 一个表格，里面有 `fastapi`、`openai`、`pypdf` 等。

> 注意：这里敲 `python`（不是全路径），因为已经在虚拟环境里了，(venv) 标志着它指向 `.venv`。

---

### 第 6 步：配置 .env（放你的 API Key）

```powershell
Copy-Item .env.example .env
notepad .env
```

记事本会打开。找到这三行，改成你自己的：

```
LLM_API_KEY=sk-你的真实key
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_MODEL=deepseek-chat
```

**base_url 和 model 怎么填**，看你用的是哪家：

| 服务商 | LLM_BASE_URL | LLM_MODEL |
|---|---|---|
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 智谱 | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` |
| 通义 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| 月之暗面 | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` |

保存（Ctrl+S），关掉记事本。

**三条注意事项**：
1. `LLM_API_KEY=` 后面**不要加空格、不要加引号**，直接跟 key
2. key 不要发到任何聊天软件、不要截图、不要提交到 git（`.gitignore` 已经挡住了）
3. 如果 key 泄露，去服务商后台删掉重新生成一个

---

### 第 7 步：装 embedding 依赖（慢，可以放到最后做）

```powershell
python -m pip install sentence-transformers
```

**这一步会下载约 2GB**（主要是 PyTorch），**10~25 分钟**，取决于网速。

**这段时间可以先去喝水。** 如果卡在某个包超过 10 分钟没动静，Ctrl+C 中断，加镜像源重试：

```powershell
python -m pip install sentence-transformers -i https://pypi.tuna.tsinghua.edu.cn/simple
```

我已经在你机器上验证过：Python 3.11.7 能正常安装，不会出现"编译失败"。

## 四、报错急救表

| 你看到的报错 | 真实原因 | 怎么办 |
|---|---|---|
| `无法将"python"项识别为 cmdlet...` | 虚拟环境没激活，或 Python 没装 | 先看提示符有没有 `(.venv)`；没有就执行第 4 步 |
| `无法加载文件 Activate.ps1，因为在此系统上禁止运行脚本` | Windows 脚本执行策略 | 执行 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned -Force` |
| `ModuleNotFoundError: No module named 'xxx'` | 包装到了别的 Python 里 | 确认 `(.venv)` 在；`where python` 看指向哪 |
| `'pip' 不是内部或外部命令` | pip 不在 PATH | 一律用 `python -m pip` 代替 `pip` |
| `SSLError` / `CERTIFICATE_VERIFY_FAILED` | 网络证书被拦截（公司网/代理） | 换手机热点试；或加 `--trusted-host pypi.org --trusted-host files.pythonhosted.org` |
| `Read timed out` | 下载太慢 | 加 `-i https://pypi.tuna.tsinghua.edu.cn/simple` |
| `ERROR: Could not build wheels for xxx` | 版本不兼容 | 把完整报错发我，别自己乱试 |
| `401 Unauthorized` / `AuthenticationError` | API Key 错或没填 | 检查 `.env` 里 key 有没有多余空格 |
| `404 model not found` | 模型名写错，或 base_url 和服务商不匹配 | 对照第三节第 6 步的表 |

**报错时请把完整内容发我。** 从 `PS D:\...>` 那行开始，到最后一行结束，全贴。只贴最后一行，信息量少 10 倍，我要多问你三轮。
